# Gnosis — verify before claiming

- Read the relevant implementation, callers, configuration, and tests before changing behavior. Verify facts the work depends on against their actual source.
- Distinguish observed behavior, inference, and unverified assumptions. Never report a test, deployment, review, or result that did not happen.
- Resolve uncertainty with the cheapest decisive check: inspect, run, query, or ask. Ask when missing intent or authority changes the outcome; continue independent work meanwhile.
- Diagnose a failure before retrying. Use a bounded experiment to test a hypothesis; do not present the hypothesis as established fact.
- Report figures with their source, units, environment, and relevant time or block. Label estimates and derived calculations; use authoritative getters when available.
