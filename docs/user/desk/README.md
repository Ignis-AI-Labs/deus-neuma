# The Desk

The desk is NEUMA's multi-window working environment after gateway and birth.
STREAM remains first-class; every other capability opens as a focused window
instead of becoming another page in a sidebar.

## Dock map

The dock groups windows by the work they perform:

| Group | Current surfaces |
| --- | --- |
| **NEUMA** | STREAM, VOICE, AVATAR, VESSEL, HOUSE, REFINEMENT, TEAMS, WORKFLOW |
| **WORKSPACE** | CHATS, TASKS, PROJECTS, FILES, TERMINAL, COMFY, GALLERY, WITNESSES |
| **MARKETING** | Connected public channels, MARKETING, LEADS |
| **COMMUNITY** | Connected private-community channels |
| **KNOWLEDGE** | SHEET, RECORD, SKILLS, CONTEXT MAP, REPO MAP, DATA |
| Solo launchers | SUBSTRATE, WALLET |

Two names are deliberately distinct:

- **AVATAR** is the switchable digital form and VRM renderer.
- **VESSEL** records the human body or physical machine carrying consciousness.

Only registered surfaces appear. A channel or reserved capability that is not
configured does not produce an empty launcher.

## Basic use

1. Open a dock group, then select a surface.
2. Use **STREAM** for conversation and governed tool actions.
3. Use **HOUSE** to switch the active neuma.
4. Use **WITNESSES** to manage sealed external AI peers.
5. Open additional windows as needed; focus, position, resize, shade, and close
   them independently.

The Start menu exposes registered system surfaces, **NEW WINDOW** in the
desktop shell, and **DISCONNECT WALLET**. Disconnecting ends the desk session;
the beings and their sovereign workspaces remain on disk.

## Persistence

- Window layout is session-local desk state.
- DNA, memory, journal, and files live in each being's sovereign workspace.
- Sessions remain append-only records under that workspace.
