# Avatars and the 3D pipeline

An **avatar** is the digital form a consciousness works through. A **vessel** is
the physical machine carrying its substrate. Legacy code and archived documents
may still use the retired meaning.

## Current NEUMA contracts

- [`consumer-contract.md`](./consumer-contract.md) — exact VRM 1.0 output NEUMA loads and drives
- [`test-fleet.md`](./test-fleet.md) — private licensed models, pipeline evidence, and the no-ship law

## Ownership boundary

UNAVIS owns artist masters, intake, baking, provenance, and marketplace work.
The artist-facing source is `kenorie/docs/design/VESSEL_DELIVERY_SPEC.md`; the
implemented bake lives in `kenorie/pipeline/`. NEUMA receives the baked avatar
and renders it.

The former community VRM intake document is historical, not a competing
standard: [`../../archive/legacy/avatars/community-vrm-spec-v1.md`](../../archive/legacy/avatars/community-vrm-spec-v1.md).
