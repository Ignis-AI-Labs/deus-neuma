# VRM Model Assets

Place VRM model files in this directory.

Default companion model should be named: `default-companion.vrm`

These files will be accessible at `/models/filename.vrm` in the application.

## Free VRM Models

You can download free VRM models from:
- https://hub.vroid.com/
- https://booth.pm/en/browse/3D%20Models

## Create Your Own

Create custom VRM models using:
- VRoid Studio: https://vroid.com/studio
