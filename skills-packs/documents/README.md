# documents — skill pack

Documents out of the house. The press (`backend/services/doc-press/`, once the
standalone Nimbus system) renders markdown into a branded PDF with a real
Chromium, no egress, saved in the being's own workspace.

| Skill | Summon | What it drives |
|-------|--------|----------------|
| `pdf` | `/pdf` (or via `use_skill`) | read the source, one `press/press_document` call with a brand kit, report the saved path |

The operator's own door: right-click any markdown path on the desk → Make PDF.
